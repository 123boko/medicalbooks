This site is a set of static pages. It has no accounts, no comment forms and no newsletter sign-up, and it does not set its own cookies.

## Hosting

The site is hosted on GitHub Pages. GitHub may log technical information such as your IP address when you load a page. See GitHub's privacy statement for details.

## Amazon links

When you follow a link to Amazon, Amazon may set cookies and collect data under its own privacy notice. This site does not receive any information that identifies you; it only receives aggregate reports of orders placed through its links.

## Changes

If analytics or other third-party services are added later, this page will be updated to list them.
